# Cursor 开发规则集

本目录包含了 Cursor 项目的开发规则和最佳实践指南。

## 文件组织

- `cursorrules_principles.md`: 通用开发原则，包括 KISS、单一职责等核心理念
- `cursorrules_init_guide.md`: 初始构建指南，包括项目结构、代码质量基线等
- `cursorrules_iteration_guide.md`: 迭代开发指南，包括渐进式修改、验证流程等
- `cursorrules_doc_guide.md`: 文档编写指南，包括结构规范、示例编写等

## 使用方式

1. 项目初始化时参考 `principles.md` 和 `init_guide.md`
2. 日常开发中参考 `iteration_guide.md`
3. 编写文档时参考 `doc_guide.md`

## 规则更新

这些规则会随着项目发展不断完善和更新。更新时请遵循：
1. 保持规则简单明确
2. 基于实践经验调整
3. 记录修改原因
