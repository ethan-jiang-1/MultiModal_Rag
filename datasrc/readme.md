# Folder Structure of `datasrc`

The `datasrc` directory contains the following structure:

```
datasrc/
├── exam/
│   ├── raw_docs/
│   └── raw_questions/
├── test/
│   ├── raw_docs/
│   └── raw_questions/
└── README.md
```
The `datasrc` directory is organized into two main subdirectories: `exam` and `test`. Each of these subdirectories contains two further subdirectories: `raw_docs` and `raw_questions`. 

- The `raw_docs` directories are intended to store raw document files.
- The `raw_questions` directories are meant for storing raw question files.

Additionally, there is a `README.md` file at the root of the `datasrc` directory that provides an overview of the directory structure and its contents.
